# Projeto de Estudos em .NET – Bootcamp Deloitte

Este repositório contém um projeto de estudos desenvolvido em .NET (aplicação de console) como parte das atividades práticas do **Bootcamp Deloitte Dotnet**.
O objetivo é consolidar conhecimentos fundamentais da plataforma .NET e da linguagem C#, por meio de exercícios práticos e exemplos aplicados.

## Objetivo

- Aplicar conceitos fundamentais da linguagem C#
- Compreender a estrutura de aplicações console em .NET
- Desenvolver raciocínio lógico e boas práticas de programação
- Exercitar leitura, escrita e manipulação de dados
- Evoluir gradualmente a organização e qualidade do código

## Funcionalidades

- Execução via terminal
- Implementação de lógica de programação em C#
- Uso de estruturas básicas da linguagem:
- Variáveis
- Condicionais
- Laços de repetição
- Métodos
- Classes

## Tecnologias Utilizadas

- **C#**
- **.NET**
- **Terminal / Console**
- **Visual Studio Code**

## Como Executar o Projeto

Pré-requisitos:

- **.NET SDK 10** instalado

## Para verificar a instalação:
```bash
dotnet --version
```

## Execução

Clone o repositório:

```bash
git clone https://github.com/ErickCastroSouza/deloitte-bootcamp-dotnet.git
cd deloitte-bootcamp-dotnet
cd /dia-01
cd /Case1
```

Restaure as dependências:

```bash
dotnet restore
```

Execute a aplicação:

```bash
dotnet run
```

A estrutura pode evoluir conforme o avanço do bootcamp e a inclusão de novos exercícios.

## Observações

- O projeto possui caráter exclusivamente educacional.
